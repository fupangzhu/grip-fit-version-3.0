================================================================
手机手感评分算法 — 结论与计算规范（直板机 X直板）
================================================================
用途：供程序按用户手机物理参数计算"手感评分"，并给出推荐值/最优区间。
数据来源：手机手感人因实验（元数据 / 实验数据 / 分析结果_1）。
评分类型：体验评分，0–10 分，11 点 Likert 量表。
分析方法：LMM 线性混合模型 + 二次多项式固定效应（被试随机截距）。

----------------------------------------------------------------
一、核心算法
----------------------------------------------------------------
每个【数值型】手感维度的评分 = 该物理参数 x 的二次函数：

    score(x) = A * x^2 + B * x + C        （结果截断到 [0, 10]）

规则：
  - A < 0  → 倒U型曲线，存在最优值 x* = -B / (2A)，x 越接近 x* 评分越高。
  - A > 0  → U型曲线，中间最差、两端较高，推荐取实验区间端点。
  - 优区间（"优"档，可画绿色推荐块）：解 A*x^2 + B*x + C = 6.6 得到的 x 区间。
        倒U型 → 取两根之间；U型 → 取两根之外、落在实验范围内的端点段。
  - 总分：18 个维度的 score 归一后，按 AHP 权重加权求和。

伪代码：
    function scoreNumeric(d, x) {
        const s = d.A * x * x + d.B * x + d.C;
        return Math.max(0, Math.min(10, s));
    }
    function optimal(d) {
        return d.A < 0 ? -d.B / (2 * d.A) : null;   // U型无单一最优
    }
    function bestInterval(d, thr = 6.6) {
        const a = d.A, b = d.B, c = d.C - thr;
        const disc = b * b - 4 * a * c;
        if (disc < 0) return null;
        const r1 = (-b - Math.sqrt(disc)) / (2 * a);
        const r2 = (-b + Math.sqrt(disc)) / (2 * a);
        const lo = Math.min(r1, r2), hi = Math.max(r1, r2);
        // 倒U: [max(min,lo), min(max,hi)]；U: 取范围内落在 [.., lo] 或 [hi, ..] 的端点段
        return d.A < 0 ? [Math.max(d.min, lo), Math.min(d.max, hi)] : 'edges';
    }
